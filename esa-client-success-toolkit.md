### 6. REVENUE IMPACT CALCULATOR

**CLIENT LIFETIME VALUE FORMULA:**
```
Average Contract Value: $______
Average Contracts Per Client: ______
Upsell Revenue Average: $______
Referral Value (20% of clients refer): $______

CLIENT LTV = (Contract Value × # Contracts) + Upsells + Referrals

EXAMPLE:
Base contract: $15,000
Average 2.3 contracts per client
Upsell average: $8,000
Referral value: $3,000

LTV = ($15,000 × 2.3) + $8,000 + $3,000 = $45,500
```

**CHURN COST CALCULATOR:**
```
Prevented Churn Value = Client LTV × Retention Rate Improvement
Cost of Retention Effort = CSM time + incentives offered
Net Retention Value = Prevented Churn Value - Cost of Retention

EXAMPLE:
Client LTV: $45,500
Retention improved from 60% to 85% = 25% improvement
Cost of retention: $2,000 (time + credit offered)
Net value: ($45,500 × 0.25) - $2,000 = $9,375
```

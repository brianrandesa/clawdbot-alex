# ESA CLIENT SUCCESS FRAMEWORK — COMPREHENSIVE GUIDE

## EXECUTIVE SUMMARY
Complete operational framework for ESA's client success processes, extracted from Brian's Claude Project Instructions PDF. This is the master reference for all client onboarding, sprint execution, team coordination, and handoff procedures.

## OFFER STACK (Pitch in order - never lead with lowest tier)
1. **DFY Ticket Sales** ($50K–$100K+ plus commission) - ESA sells their tickets
2. **Autopilot Pro** ($25K / 6 months) - ESA manages ads first 90 days  
3. **Event AutoPilot** ($15K / 90 days) - Core DWY offer
4. **Marketing Pod** ($2,497/month) - Post-sprint ongoing ad management

## 7-STEP CLIENT ONBOARDING FLOW
### Step 1: Payment Confirmed (Day 0)
- Stripe triggers GHL welcome sequence
- Slack channel created: `[FirstName]-ESA`
- Onboarding intake form sent
- SLA: Kickoff call scheduled within 48 hours

### Step 2: Intake Form Completion (48-72 hrs)
**Kim holds the gate - no form, no call**
Collects: Event details, pricing, revenue goals, ad access, audience size, team members, brand assets, challenges, success metrics

### Step 3: Kickoff Strategy Call (60 min, Fathom recorded)
**Denise/Ops Manager runs**
Agenda: Welcome (5m) → Event details (10m) → Deep dive goals (15m) → Event math (10m) → Custom elements (10m) → Build walkthrough (7m) → Communication expectations (3m)

**Post-call:** Paste Fathom transcript into Claude project with prompt: "Build the custom client roadmap from this transcript using our 90-day sprint framework."

### Step 4: Custom Roadmap Build (24-48 hrs)
**Ops Manager + James build from transcript + intake**
Includes: Custom 90-day milestones, deliverable owners, event math, GHL snapshot selection, deviation notes

Goes into: ClickUp workspace + Slack pinned message

### Step 5: Client Roadmap Sign-Off
**Required before build starts - scope protection**
Client approves in Slack, Kim logs in ClickUp

### Step 6: ClickUp Workspace Creation  
Kim builds from approved roadmap (not template), client gets view access

### Step 7: Sprint Execution
Shah/GHL team executes, Ops Manager runs weekly calls, Kim sends 3x weekly updates

## 90-DAY SPRINT - 5 PHASES

### Phase 1 - Foundation (Days 1-14)
**Goal:** Lock everything before touching GHL
**Deliverables:** Intake complete, kickoff call, roadmap approved, GHL sub-account created, ClickUp built, event math model, 100-point checklist
**Gate:** Client approves roadmap → build begins

### Phase 2 - System Build (Days 15-35)  
**Goal:** Full GHL system live and QA'd
**Deliverables:** Funnels built, automations installed, pipelines configured, tracker dashboard, SOPs written, sales scripts, QA complete, client walkthrough
**Gate:** Client understands and can navigate system

### Phase 3 - Ads Launch (Days 36-50)
**Goal:** Traffic flowing, leads coming in
**Deliverables:** Ad creative produced, Meta campaigns live, DM automation, lead flow tested, team trained, daily monitoring first 7 days
**Gate:** CPL within target, client team working leads

### Phase 4 - Training + Optimization (Days 51-75)
**Goal:** Client team runs independently  
**Deliverables:** Weekly training calls, sales coaching, ad optimization, system adjustments, team accountability, case study starts
**Gate:** Client team fully independent, ESA in coaching role only

### Phase 5 - Handoff + Renewal (Days 76-90)
**Goal:** Clean exit with renewal conversation
**Deliverables:** System audit, next event playbook, results summary, renewal discussion, offboarding checklist
**Gate:** Client signs off + renewal decision documented

## SPRINT HEALTH STATUS SYSTEM
- 🟢 **On Track:** Normal cadence
- 🟡 **At Risk:** 1 missed milestone - heightened monitoring  
- 🔴 **Behind:** 2+ missed milestones - **immediate intervention call**
- ⚫ **Escalated:** Refund risk - Brian involved

## SCOPE BOUNDARIES

### WE DO:
- GHL system build (snapshots, funnels, automations, pipelines)
- Meta ad setup and launch support
- Sales scripts and training  
- Weekly coaching calls
- Ticket tracker dashboard
- SOPs for client's team

### WE DON'T:
- Full-service social media management
- Video editing (beyond ad creative in Autopilot Pro)
- Event logistics (venues, catering, registration platforms)
- Ongoing ad management (unless Autopilot Pro)

- Managing client's team post-handoff

## ESCALATION PROCEDURES

### Escalate to Ops Manager:
- Client mentions refund/cancellation
- 2+ weeks behind on approvals
- Build delayed 3+ business days
- Significant scope change requests
- CPL 2x+ target after 7+ days

### Escalate to Brian:
- Formal refund request
- Relationship at serious risk  
- Enterprise/DFY critical issue
- Legal/contract/payment dispute

**Rule:** Every client gets documented next-step conversation. Never quietly go quiet.

# ESA Studio vs Victoria – When to Use Which

**Purpose:** Guide team on the right tool for funnel/landing page work.

---

## Quick Decision

| Task | Tool | Why |
|------|------|-----|
| Deploy standard client system (pipeline, funnel, automations) | **Victoria** | 4 templates, one Slack request, done |
| Custom landing page design | **ESA Studio** | AI strategist, copywriter, designer pipeline |
| Headline lab, competitor spy, VSL generator | **ESA Studio** | Specialized AI tools |
| Speed-to-lead, nurture sequence | **Victoria** | Part of template or browser automation |
| Quick funnel for new client | **Victoria** | general-business template |
| Multi-variant testing, split tests | **ESA Studio** | Advanced features |
| SOP or process question | **Victoria** | She knows Notion, ClickUp, framework |

---

## ESA Studio (esabuilder.com)

**Strengths:**
- Full funnel generator (strategist → copywriter → designer → QA)
- Landing page generator with themes
- Headline Lab, Competitor Spy
- Email/SMS/Ad/VSL generators
- Client management, version history
- GHL webhook for leads

**Who uses it:** Brian, Denise, team members with access  
**When:** Custom creative, new designs, headline testing, client-specific landing pages

---

## Victoria (Slack @Victoria)

**Strengths:**
- Deploy 4 GHL templates instantly
- Create funnel pages, workflows, speed-to-lead
- Pipeline, tags, custom fields
- QA test funnel
- Process questions, SOP lookup
- ClickUp, Notion, GHL data

**Who uses it:** Denise, Kim, Shah, Hamza, James – anyone in #client-success  
**When:** Standard client onboarding, funnel deployment, process questions, GHL operations

---

## Hybrid Workflow

1. **Kickoff call done** → Roadmap approved
2. **Standard build** → @Victoria deploy template in #client-success
3. **Custom landing page needed** → Team uses ESA Studio, generates creative
4. **Victoria** deploys base system; team or Shah adds ESA Studio output to GHL if needed
5. **Shah** – Final QA, client walkthrough

---

## Channel to Use

- **#client-success** – @Victoria for funnel builds, GHL deployments, client system requests
- **ESA Studio** – Direct app access when doing custom creative work
